# Scope

- Audited surface: the current Local Markdown desktop editor in `local-markdown.html`, rendered from the repository root.
- Primary user: a desktop Chrome or Edge user who wants to edit local Markdown without installing an app or creating an account.
- Primary task: open a local Markdown file or folder, edit its contents, and keep changes saved locally.
- Constraints: preserve the local-first privacy model, File System Access API workflow, single-file vanilla HTML/CSS/JavaScript architecture, responsive sidebar, three editing views, and existing light/dark themes.
- Accessibility floor: keyboard-operable primary controls, visible focus, semantic labels, and WCAG AA contrast for normal text.
- References or competitors: none supplied; the audit scores the shipped surface on its own behavior.
- Out of scope: Excalidraw's third-party editor UI, export document styling, and narrow mobile layouts where local file APIs are not the intended primary environment.
